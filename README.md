# Convite Bridgerton

Site estático preparado para publicação pelo GitHub Pages. O fluxo publica somente os
HTMLs e os recursos necessários para o convite, sem incluir imagens de convite
ou QR Pix que contenham dados pessoais.

Depois do primeiro deploy, o convite estará disponível em:

https://adriorrosa.github.io/Teste/bridgerton.html

O deploy é executado ao enviar alterações para `main` ou manualmente pela aba
Actions do GitHub.
